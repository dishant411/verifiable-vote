# Security policy

This is a research preview, not a supported production election service. No formal response-time commitment or external security audit exists yet. Do not run real elections or collect real identity documents.

Report sensitive vulnerabilities through GitHub's private vulnerability reporting **if enabled**, or privately to the repository owner through an established private channel. Do not post secrets or exploitable election vulnerabilities in public issues. Private reporting enablement/contact must be confirmed before inviting a real pilot; no fabricated security email is provided.

Security-sensitive protocol changes require written threat assumptions, preserved test evidence, upstream consultation and external review. Never introduce homemade cryptography or silently fall back to plaintext/mock encryption.
